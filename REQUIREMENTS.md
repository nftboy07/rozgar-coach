### Event identity
- **Name:** Code for a Billion — Bharat Agentic-AI Hackathon 2026
- **Organiser:** Code for India (CFI), civic-tech nonprofit founded 15 Aug 2013
- **Format:** Fully virtual / online, 90 days
- **Official IDE:** AgentFoundry.me — every participant gets **1M free smart-code tokens**
- **API / tech partner:** xSpan CareHub (xSpan.ai); knowledge/skilling partners: NASSCOM IT-ITeS Sector Skills Council & FutureSkills Prime (MeitY–NASSCOM)

### Timeline (official)
| Date | Milestone |

### Prizes
- **₹18,00,000 total pool**
- Per track / category: **1st ₹1,50,000 · 2nd ₹1,00,000 · 3rd ₹50,000**
- Sponsor recognition awards: "Best Use of AgentFoundry Agents", "Best xSpan CareHub Integration"

### Eligibility
- Students, professionals, and indie developers — **solo or in teams**
- **Anyone, anywhere on Earth** (100% virtual)
- **Free** to enter

### The challenge — 10 impact areas (pick one, define your own problem statement)
1. Education · 2. Sanitation · 3. Waste Management · 4. Clean Air · 5. Clean Water · 6. Health · 7. Timely Justice — Legal Backlog · 8. Transportation Safety · 9. Livelihood for the Uneducated · **10. Tech Employment for Youth**

**Our track — #10 Tech Employment for Youth** (official wording): *"Job discovery, portfolio building, apprenticeships, hiring signal for first-time coders."*

There are no pre-set project briefs: each entrant defines the problem, its scale (how many people) and severity themselves.

### Submission / deploy requirements (official "How to participate" — 4 steps)
1. **Build in AgentFoundry** — start the project in AgentFoundry.me, the official IDE. Signing up + creating a project in the IDE *is* the hackathon entry.
2. **Publish your repo** — push work to a **public GitHub repo with a clear README**.
3. **Record a demo** — a **2–3 minute video walkthrough, OR a live link** judges can open.
4. **Submit on GitHub** — a structured form capturing **problem statement, repo, and demo**.

Hard requirements for judging:
- Project **deployed to any cloud by 15 Nov 2026** (GitHub Pages satisfies "any cloud" deployment)
- Project **open-sourced under Apache-2.0 or MIT**, released to the Code for India GitHub organisation model so NGOs/government can adopt it (entrant retains attribution)
- Judging covers **only** projects actually deployed by the deadline

### Judging criteria (official — 4 criteria, weighted equally, 25% each)
| Weight | Criterion | What it means |
|---|---|---|
| 25% | **Size of the problem** | How many citizens face it |
| 25% | **Severity of the problem** | Human suffering or economic loss it causes |
| 25% | **Quality of the solution** | Design craft plus real effectiveness |
| 25% | **Proven impact** | Actual deployment data, not intentions |

Judging summary on the timeline also phrases the review as: **impact, openness, and technical quality**. A full rubric is linked from the official page ("See the full judging rubric" → GitHub).
